## 📌 2. GIỚI THIỆU REPOSITORY

Repository này được tạo ra nhằm lưu trữ các bài tập thực hành trong quá trình học tập và tìm hiểu về **Git và GitHub**.

Thông qua các bài thực hành, em được làm quen với việc quản lý mã nguồn, theo dõi lịch sử thay đổi, tạo nhánh, đồng bộ dữ liệu và cộng tác trong các dự án lập trình.

## 🎯 3. MỤC TIÊU HỌC TẬP

- Hiểu các khái niệm cơ bản về Git và GitHub.
- Biết cách tạo và quản lý Repository.
- Thành thạo các thao tác Add, Commit, Push và Pull.
- Biết tạo, chuyển đổi và quản lý Branch.
- Biết Clone Repository về máy tính.
- Thực hành làm việc nhóm thông qua Contributor.
